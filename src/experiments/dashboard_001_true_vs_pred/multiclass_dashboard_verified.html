Metrics Guide

This dashboard evaluates a multi-output multiclass classification problem — each observation is assigned one of three categorical labels (P, F, P1) across eight independent output columns. The metrics below are calculated per column and then summarised across all columns.

Click any metric to expand its business description, mathematical definition, and references.

📊 Business Description

A confusion matrix is a scoreboard that shows, for every true label, how often the model agreed and how often it got confused. Each row represents a real (ground truth) outcome; each column represents what the model predicted. The diagonal cells are correct calls — everything off-diagonal is a mistake.

For this dashboard, each output column has its own 3×3 confusion matrix covering labels P, F, and P1. Heatmap color intensity reflects how many observations land in each cell.

∑ Mathematical Definition

For a column with classes \(1, \dots, n\), the confusion matrix entry at row \(i\), column \(j\) is:

$$M[i][j] = \#\{\,\text{observations where truth} = \text{class}_i \text{ and prediction} = \text{class}_j\,\}$$

Diagonal entries \(M[i][i]\) are correct predictions. Off-diagonal entries \(M[i][j],\; i \neq j\) are misclassifications.

M[i][j] = count of (truth = class_i AND pred = class_j)
Diagonal M[i][i] → correct · off-diagonal → errors
References
1
Kohavi, R. & Provost, F. (1998). Glossary of terms. Machine Learning, 30(2–3), 271–274. — Defines confusion matrix terminology in ML contexts.
2
Stehman, S. V. (1997). Selecting and interpreting measures of thematic classification accuracy. Remote Sensing of Environment, 62(1), 77–89.
📊 Business Description

Accuracy is the simplest measure: out of all predictions made, what fraction were correct? A value of 96% means the model labelled 96 out of every 100 observations correctly for that column.

Accuracy is easy to communicate but can be misleading when one label is far more common than others. If 90% of observations are label P, a model that always predicts P reaches 90% accuracy without learning anything. For balanced datasets like this one, accuracy is a reliable headline figure.

∑ Mathematical Definition
$$\text{Accuracy} = \frac{\sum_{i} M[i][i]}{\sum_{i}\sum_{j} M[i][j]} = \frac{\text{Correct predictions}}{\text{Total observations}}$$

\(M[i][i]\) = diagonal cell (truth = class \(i\), prediction = class \(i\)). The denominator is the sum of all cells in the confusion matrix.

Accuracy = sum(M[i][i]) / sum(all M[i][j])
= correct predictions / total observations
References
1
Powers, D. M. W. (2011). Evaluation: From precision, recall and F-measure to ROC, informedness, markedness & correlation. Journal of Machine Learning Technologies, 2(1), 37–63.
📊 Business Description

Precision answers: "Of all the times the model predicted label X, how often was it actually label X?" High precision means few false alarms — when the model says P, it really means it.

In a business context: if label F triggers a costly intervention, high precision for F ensures resources are not wasted on wrong cases. The dashboard reports Macro Precision — the simple average of per-class precision values, giving each label equal weight regardless of how common it is.

∑ Mathematical Definition
$$\text{Precision}(k) = \frac{TP_k}{TP_k + FP_k} \qquad (\text{defined as } 0 \text{ if denominator} = 0)$$ $$\text{Macro Precision} = \frac{1}{n}\sum_{k=1}^{n} \text{Precision}(k)$$

\(TP_k = M[k][k]\) (true positives for class \(k\)).
\(FP_k = \sum_{i \neq k} M[i][k]\) (other classes predicted as \(k\)).

Precision(k) = TP_k / (TP_k + FP_k) [0 if denom = 0]
Macro Precision = mean of Precision(k) over all k
References
1
Manning, C., Raghavan, P., & Schütze, H. (2008). Introduction to Information Retrieval. Cambridge University Press. Chapter 8: Evaluation in information retrieval. nlp.stanford.edu/IR-book
2
Sokolova, M. & Lapalme, G. (2009). A systematic analysis of performance measures for classification tasks. Information Processing & Management, 45(4), 427–437.
📊 Business Description

Recall answers: "Of all the observations that truly belong to label X, how many did the model actually catch?" High recall means few cases are missed — the model is thorough.

If missing a true F case is dangerous (e.g. a defect that reaches customers), high recall for F is critical, even if it means occasionally flagging a non-F observation. Recall and Precision trade off against each other; the F1 score balances them. The dashboard reports Macro Recall — the unweighted average across all class recalls.

∑ Mathematical Definition
$$\text{Recall}(k) = \frac{TP_k}{TP_k + FN_k} \qquad (\text{defined as } 0 \text{ if denominator} = 0)$$ $$\text{Macro Recall} = \frac{1}{n}\sum_{k=1}^{n} \text{Recall}(k)$$

\(TP_k = M[k][k]\).
\(FN_k = \sum_{j \neq k} M[k][j]\) (true class \(k\), predicted as something else).

Recall(k) = TP_k / (TP_k + FN_k) [0 if denom = 0]
Macro Recall = mean of Recall(k) over all k
References
1
Manning, C., Raghavan, P., & Schütze, H. (2008). Introduction to Information Retrieval. Cambridge University Press. nlp.stanford.edu/IR-book
2
Visa, S., Ramsay, B., Ralescu, A., & van der Knaap, E. (2011). Confusion matrix-based feature selection. MAICS 2011, 710, 120–127.
📊 Business Description

The F1 score is the single number that balances Precision and Recall. It rewards models that are both accurate (few false alarms) and thorough (few missed cases). A model that cheats by predicting every observation as the same class gets a low F1 even if its raw accuracy looks acceptable.

Macro F1 averages the per-class F1 scores with equal weight for each label — so a rare label like P1 matters just as much as the common label P. This makes Macro F1 the recommended headline metric when all labels are equally important to the business.

∑ Mathematical Definition
$$F_1(k) = 2 \cdot \frac{\text{Precision}(k) \cdot \text{Recall}(k)}{\text{Precision}(k) + \text{Recall}(k)} \qquad (\text{defined as } 0 \text{ if denominator} = 0)$$ $$\text{Macro F1} = \frac{1}{n}\sum_{k=1}^{n} F_1(k)$$

F1 is the harmonic mean of Precision and Recall. The harmonic mean penalises large imbalances — a model scoring 1.0 Precision but 0.0 Recall gets \(F_1 = 0\).

F1(k) = 2 * Precision(k) * Recall(k) / (Precision(k) + Recall(k))
Macro F1 = mean of F1(k) over all k
Why harmonic mean? The arithmetic mean of 1.0 and 0.0 is 0.5 — misleadingly high. The harmonic mean of 1.0 and 0.0 is 0 — correctly reflecting total failure on one dimension.
References
1
van Rijsbergen, C. J. (1979). Information Retrieval (2nd ed.). Butterworths. — Original derivation of the F-measure as a weighted harmonic mean.
2
Opitz, J. & Burst, S. (2019). Macro F1 and macro F1. arXiv:1911.03347. — Clarifies averaging strategies for multiclass F1. arxiv.org/abs/1911.03347
3
Scikit-learn documentation: sklearn.metrics.f1_score — Reference implementation.
📊 Business Description

Weighted F1 is a variant of the F1 score that gives more influence to labels that appear more frequently in the data. If P makes up 60% of observations, its F1 contributes 60% of the weighted score.

Use Weighted F1 when you care about overall performance on the data as it actually arrives — the common labels matter more because they occur more. Use Macro F1 when you want every label to count equally regardless of frequency.

∑ Mathematical Definition
$$\text{Weighted F1} = \frac{\displaystyle\sum_{k} F_1(k) \cdot \text{support}(k)}{\displaystyle\sum_{k} \text{support}(k)}$$

\(\text{support}(k)\) = total ground-truth observations belonging to class \(k\) (row sum in the confusion matrix).

Weighted F1 = sum(F1(k) * support(k)) / sum(support(k))
References
1
Sokolova, M. & Lapalme, G. (2009). A systematic analysis of performance measures for classification tasks. Information Processing & Management, 45(4), 427–437.
2
Scikit-learn documentation: sklearn.metrics.f1_score (average='weighted').
📊 Business Description

Hamming Accuracy is the headline cross-column metric: it counts every individual label prediction across all eight output columns and asks what fraction were correct. One observation contributes eight label decisions; an error in any one of them counts as one wrong label out of eight.

This is the complement of the Hamming Loss (the fraction of wrong labels), which is commonly used in multi-label classification literature. It gives a single, intuitive number that reflects how well the model does across the entire output space, not just on one column.

A Hamming Accuracy of 93.9% means that across all rows and all eight columns, roughly 94 out of every 100 individual label predictions are correct.

∑ Mathematical Definition
$$\text{Hamming Accuracy} = 1 - \text{Hamming Loss}$$ $$= \frac{\displaystyle\sum_{c \in \text{Columns}} \sum_{i} M_c[i][i]}{\displaystyle\sum_{c \in \text{Columns}} \sum_{i}\sum_{j} M_c[i][j]}$$

\(M_c\) = confusion matrix for column \(c\).
Numerator = sum of all diagonal entries across all 8 matrices (correct predictions).
Denominator = \(N \times 8\), where \(N\) = number of rows.

Hamming Accuracy = 1 - Hamming Loss
= sum_c sum_i M_c[i][i] / sum_c sum_i sum_j M_c[i][j]
= total correct / (N * num_columns)
Hamming Loss vs Hamming Accuracy: The literature typically defines Hamming Loss (lower is better). This dashboard reports Hamming Accuracy = 1 − Hamming Loss (higher is better), consistent with how Accuracy is reported for the individual columns.
References
1
Hamming, R. W. (1950). Error detecting and error correcting codes. Bell System Technical Journal, 29(2), 147–160. — Original definition of the Hamming distance.
2
Schapire, R. E. & Singer, Y. (2000). BoosTexter: A boosting-based system for text categorization. Machine Learning, 39(2–3), 135–168. — Introduces Hamming Loss in the multi-label ML context.
3
Scikit-learn documentation: sklearn.metrics.hamming_loss.
📊 Business Description

Macro averaging gives each class the same vote. A rare label like P1 with only 50 examples influences the final score just as much as P with 300 examples. Use macro when all classes are equally important to detect — for example, when a missed P1 is just as costly as a missed P.

Weighted averaging gives each class a vote proportional to how many observations it has. Common classes steer the score more. Use weighted when you want a metric that reflects overall performance on the real-world distribution of data.

For balanced datasets (equal class counts), macro and weighted averages are identical. This dashboard shows both so stakeholders can choose the appropriate lens for their use case.

∑ Mathematical Comparison
$$\text{Macro F1} = \frac{F_1(P) + F_1(F) + F_1(P1)}{3}$$ $$\text{Weighted F1} = \frac{F_1(P)\cdot n(P) + F_1(F)\cdot n(F) + F_1(P1)\cdot n(P1)}{n(P) + n(F) + n(P1)}$$

\(n(k)\) = number of ground-truth observations of class \(k\).

Macro F1 = (F1(P) + F1(F) + F1(P1)) / 3
Weighted F1 = (F1(P)*n(P) + F1(F)*n(F) + F1(P1)*n(P1)) / (n(P)+n(F)+n(P1))
References
1
Opitz, J. & Burst, S. (2019). Macro F1 and macro F1. arXiv:1911.03347. arxiv.org/abs/1911.03347
2
Sokolova, M. & Lapalme, G. (2009). A systematic analysis of performance measures for classification tasks. Information Processing & Management, 45(4), 427–437.
